# Atividade API de Produtos

## Descrição

Aplicação desenvolvida para praticar a criação de uma API com Node.js e Express e o consumo de dados utilizando JavaScript e Fetch.

A aplicação disponibiliza produtos através de uma API e apresenta esses produtos no frontend.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- CORS
- Fetch API
